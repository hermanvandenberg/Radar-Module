# Radar-Module

Oefenmodule voor het radarexamen binnenvaart, gebaseerd op het lesboek *Radar, cursus varen met behulp van radar*.

**Oefenen:** open de module op je telefoon via GitHub Pages: https://hermanvandenberg.github.io/Radar-Module/

## Hoe het werkt
- 7 hoofdstukken: radartechniek, bediening, echo's, varen op radar, BPR, RPR en SRW.
- Elk hoofdstuk wisselt korte uitleg af met oefenvragen en eindigt met een eindtoets van 15 willekeurige vragen.
- Alle vragen goed = geslaagd. Anders zie je hoeveel vragen je fout had en wat het juiste antwoord was.
- Alle hoofdstukken staan open en je kunt ze zo vaak oefenen als je wilt. Per hoofdstuk zie je hoe vaak je geslaagd bent.
- Je voortgang wordt alleen op je eigen telefoon bewaard (in de browser).

## Bestanden
- `index.html`: de complete module (één bestand, geen installatie nodig).
- `lesstof/`: samenvattingen per hoofdstuk en de verwerkte correcties uit de antwoorden.
